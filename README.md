# Индикатор микроклимата бани с управлением вентиляцией

## Описание
Устройство контроля микроклимата парной русской бани на базе ESP8266 с отображением температуры и влажности воздуха, контролем температуры воды в баке и управлением вентилятором проветривания.

## Техническое задание
Версия: R1.0.0
Дата релиза: 26.07.2026

## Основное оборудование
- **Контроллер**: NodeMCU v3 (ESP8266)
- **Датчики**: 2× AHT10 (I2C), 1× DS18B20 (OneWire)
- **Дисплей**: GMG12864-06D Ver.2.2 (SPI)
- **Управление**: 2 кнопки, реле вентилятора

## Функционал
- Отображение температуры и влажности в реальном времени
- Управление вентилятором кнопками и веб-интерфейсом
- Графики изменения параметров за 30 минут
- Журнал ошибок
- Меню настроек
- Wi-Fi Access Point
- Сохранение пользовательских настроек во Flash

## Структура проекта
```
src/
├── main.cpp          # Главный файл
├── config.h          # Конфигурация GPIO и параметры
├── sensors.h/cpp     # Работа с датчиками
├── display.h/cpp     # Работа с дисплеем
├── buttons.h/cpp     # Обработка кнопок
├── ventilator.h/cpp  # Управление вентилятором
├── wifi.h/cpp        # Wi-Fi и веб-интерфейс
├── settings.h/cpp    # Сохранение настроек
├── errors.h/cpp      # Журнал ошибок
└── utils.h/cpp       # Утилиты
```

## Сборка и загрузка
```bash
# Требуется PlatformIO
pio run -t upload
pio device monitor
```
